Use case: ui-mockup
Asset type: high-fidelity desktop application design study, full app screenshot, 1600 by 1000 landscape composition.
Primary request: Reimagine Jamella's classic Diablo II character editor as a beautifully crafted modern Windows desktop tool called AKARA. Preserve the classic productive inventory-editor layout, with tangible Diablo-style items, while giving it contemporary precise desktop typography and disciplined spacing. This is a character editor, not a dashboard or a game launcher.
Layout: Full-bleed desktop app. Compact 32px native titlebar with a tiny gold arch mark and AKARA at upper left, Windows caption buttons at upper right. Under it a 44px command row: Open, character selector showing Selene / Sorceress / 85, Clone, undo/redo; right-aligned Review and small amber Save button. Next a 38px horizontal tab strip: Character, Skills, Items (selected), Mercenary, World, Library. Everything below is working space, no giant branding rail or heading. Three practical panes separated by fine vertical draggable dividers: a 235px wide searchable Item Catalog at left, a generous central equipment/inventory workspace, a 315px Properties pane at right. Central workspace shows a compact classic symmetrical equipment paperdoll on left with ten genuine slots (helm top, amulet upper right, two hands flanking armor, gloves and boots on sides, belt and two rings bottom); a ten-column eight-row inventory grid beside it, each item spans proper full cells, with tasteful familiar painted small Diablo-style sword, shield, leather gloves, armor, potions, books and charms. Small I / II selector above equipment. Storage tabs Inventory / Stash / Cube / Belt above the grid. Below the grids, small move / import / refill commands and a restrained reusable-items tray. Properties panel shows a 64px orb-on-staff icon beside The Oculus in muted antique gold, base label Swirling Crystal, and compact aligned property rows with blue magical properties. Sections: Properties, Sockets, Advanced. Small Edit / Move / Duplicate actions at the bottom. A 28px statusbar across bottom: Local character, No pending changes, Reimagined. No panels unrelated to items.
Style: Exceptionally polished dense native desktop utility, precise pixel-aligned layout with breathing room inside functional groups. Warm graphite #25282A chrome, slightly lighter #303437 panel headers, dark #191D20 inventory canvas, fine #444A4E dividers. Off-white #E5E7E7 type and #A8AFB2 secondary type. Muted antique gold #C3A66D only for active tab underline, selected cell edge and Save. Blue #9AB8EA magical stats. Segoe UI / Inter style sans-serif 13–14px labels, 18px section headings. Flat surfaces, 3px corner radius at most, subtle separations, believable Windows utility. Tiny monochrome outline toolbar icons. Diablo character comes from the painted items and inventory proportions, never from ornamental chrome. Screen fills the composition, no laptop, hands, scenery or perspective.
Constraints: No portraits, no characters standing behind UI, no fake worn metal, no stone carvings, no filigree, no bevels, no yellow borders around every panel, no glow, no decorative gradient, no giant serif titles, no dashboard cards, no huge empty margins, no marketing text. Avoid rendering all objects as the same blue charm. Render clear real typography and a coherent slot/grid topology. This is only a design candidate; all real data and controls will be implemented natively, never as a baked screenshot.
