# AKARA 0.3.0 — native desktop

AKARA now opens as a native Windows application built with WPF and .NET 10. The portable package contains the desktop editor, the standalone JSON CLI, and their runtimes.

## Changes

- Replaced the shipped browser interface with eight native editor views: character, skills, equipment, mercenary, world, item workshop, loadout library, and reviewed changes/backups.
- Added an original arch-and-amber mark, reviewed inventory illustrations and hand-authored class emblems. Rejected portrait candidates are excluded from production.
- Added native equipment and inventory controls, both weapon sets, all nine Reimagined mercenary slots, and keyboard-accessible item actions.
- Connected native character creation/cloning, item design, blueprint and loadout import/export, build guides, undo/redo, review, guarded save, and exact backup restoration to the shared Core.
- Kept the agent CLI and its JSON contracts. The historical browser client remains in source, outside the shipped package.
- Made inspection and preview consistently respect Core's injected game-state detector. Production continues to use the real process detector.

## Verification

- 86 Core integration checks passed with private fixtures and local Reimagined tables.
- 48 native behavior checks passed with private copies, including review gating, undo/redo, two-way equipment selection, item design, clone edits, save/backup/restore, and open/closed game-state handling.
- Inspected all eight rendered WPF views, plus 1280 × 900 and 3440 × 1440 layouts. Offscreen captures render the actual application controls and do not open a visible window or send desktop input.
- Reviewed the mark at 32/64 px and all 24 item illustrations after correcting crop bounds. Production art audit has no open findings.

These checks do not establish in-game testing of all eight classes. No game tables, saves, private screenshots, or mod packages are included. Custom items use existing native bases and encodable properties; new game definitions and artwork require a separate mod-data workflow.

Download the Windows archive, extract it and open **Akara.exe**. Use **akara-cli.exe help** for automation. See the included **LEEME.txt** and **CLI.md** for details.
