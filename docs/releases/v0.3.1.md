# AKARA 0.3.1 — consistent item illustrations

Moving an Oculus from equipment to the personal stash could change its illustration into a charm. Item art now follows the native base/type and compatible equipment slots, preserving the category when an item moves. This also fixes stored armor, shields, gloves, boots, belts and other weapon families. Unknown bases use a neutral marker.

Regression checks cover native orb equipment before/after movement, stored armor, actual runes and unknown items. Save transformations and persistence rules are unchanged.

A manual end-to-end test used the native GUI to clone a private Sorceress, change two skills and swap weapons, review and save the new file. The clone loaded in Reimagined 3.1 on Hell difficulty; its item tooltip, skill tree, mercenary and subsequent in-game save were checked. The original save remained byte-identical. Private saves and screenshots are excluded from this release.
